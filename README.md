# knowledge-harness

A Claude Code harness for knowledge work — academic research first (question → literature → synthesis → draft → submit), then analysis/reports, PKM, and long-form writing.

Success criterion: **trustworthy output** — every claim traceable to a real source, zero fabricated citations.

Planning happens on the [wayfinder map](../../issues) (label `wayfinder:map`). `analysis/dev-harness-analysis.md` is the anatomy of the software-dev harness this re-imagines.
