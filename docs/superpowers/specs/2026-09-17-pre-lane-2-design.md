### 3.6 #133 — the gate refuses a dirty tree

**As filed (2026-09-16):** "`scripts/mutation_gate.py` in gate mode selects the modules to measure from `git diff <base>...HEAD`, so a change that is not yet committed contributes nothing to the changed set: the gate prints 'no changed research_vault modules' and exits 0. **At `HEAD`:** `changed_modules` (`:366-393`) runs only the diff; `_gate` (`:844-854`) prints the pass line on an empty list; no `git status` call exists in the script. ### 6.1 Where a reason lives (decision 08)
