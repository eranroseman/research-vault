## The fan-out experiment (2026-09-23)

Runs A and B share one paper, one skill text, and the same stage 1 extraction and stage 2 lists per run; they differ only in whether stage 3 runs as one subagent or nine, one per dimension.

Nine judges each hold the whole paper and cannot see each other, so each rediscovers the same central defects: all nine cite Algorithm 1, eight of nine cite the unsupported calibration footnote, five of nine independently report that the paper carries no evaluation. Three dimensions (Importance, Credibility, Generalizability) returned nothing another dimension had not also found.

Fan-out pays when the lenses partition the artifact, as a section-by-section manuscript review does. These nine dimensions partition the judgment, not the paper, so the nine returns overlap and stage 4 has to unpick them, and where a duplicate group lands stops being mechanical. The skill keeps one stage 3 subagent.

Two defects the experiment exposed in the skill itself, both since fixed: the return-time evidence screen could be read as rejecting any point whose Evidence field also named a background criterion (0 dropped under one reading, about 25 under the other), and numbers labelled "derived" sat outside stage 5's scope with nothing else checking them, so a wrong one survived until the main context caught it by chance.

## Whether Assumptions needs its own judge (2026-09-23)

Run B's per-dimension fan-out produced three findings run A missed, all from its Assumptions judge: OpenAlex aggregates from CrossRef so three-way author agreement is not independent corroboration; Algorithm 1 line 14 labels authors as CrossRef's when line 4 permits another origin; the two-confirmed-author gate excludes every single-authored work. The question was whether that needed a second subagent or a sharper demand.

Run C sharpened the demand instead: every premise the method depends on carries the Location of the step, line, equation, or condition that depends on it, and the method's steps are walked rather than the premises read off its prose. Scalability got the parallel treatment, every claimed scale checked against a rate computed from the paper's own figures.

One judge under the sharpened bounds reached all three. Assumptions went from four conceptual assumptions with no line citations to nine numbered premises, three of them false against the paper's own text; Scalability produced 4.6 days for a conference submission round and 20.4 hours for the accepted-papers corpus. Citing a line forces reading it, which is what a dedicated judge was buying. The skill keeps one stage 3 subagent, and the depth lives in the bound rather than in the fan-out.

The run also vindicated the derived-number recompute added to stage 4 the same morning: it corrected six numbers the judge had produced, one built on a per-paper reference count the paper never states and one that read the 800 ms batch interval as a per-call delay. Stage 5 does not check derived numbers by design, so all six would have shipped.

Five skill defects the run exposed, since fixed: front matter had no addressable Location, so a true finding about the identifier stamp was dropped as inadmissible; stage 1 claims were handed to the judge as material but were not admissible evidence; stage 4's protection of verdict sentences read as binding stage 5 too; the claimed-scale rule was unsatisfiable where the paper states no multiplier; and the dimension bullets spelled the background files differently from the brief's own input list.

## The verdict bound and the relevance test (2026-09-23)

Both were added after five reports on one paper showed two separate inflations: the verdict sentence grew from a median of 30 words under the old word ceiling to 57 without it, and the "Why it matters" field grew from 20 words to 51 and then 86 for the same defects. Run D tested both at once, which is sound because they act on different surfaces: the bound acts inside the judge subagent on verdicts, the relevance test in the main context on points, and stage 4 protects verdict sentences so it cannot shorten one. The stage 3 return was archived before stage 4 ran, so the effects stay attributable.

**The verdict bound works.** Nine verdicts at 20 to 31 words, median 29, every one a single sentence. Points returned held at 57 against run C's 58 on the same sharpened bounds, so nothing was displaced from the verdict down into the points.

**The relevance test failed, and could not have succeeded.** It removed nothing. The judge brief requires a "Why it matters" field on every point, so "moves no verdict" is a claim that can never be made about a point the brief accepted. A filter in the pruning stage cannot undo a demand made in the writing stage. The rule is removed, and the bound it was reaching for now sits in the brief: Observation and Why it matters are one sentence each.

**Stage 4's first rule was a landmine.** Read literally, "a Discussion sentence that restates the paper without carrying a judgment" removes every point, because each point's Observation field restates the paper by design with the judgment quarantined in "Why it matters". Run D noticed, chose the narrow reading, and said so; a different reader empties the Discussion. The rule now names free-standing prose only and puts Observation fields explicitly out of scope.

Three smaller ambiguities the run resolved by judgment, since fixed: whether an unnumbered stage 1 extraction field counts as evidence where the rule admits numbered claims (it does not, and the fact it carries has a paper Location of its own); which stage catches a returned point resting on knowledge the paper never states (assembly, which moves it to the did-not-check section); and the appendix heading disagreeing with the body sentence about what the appendix holds.

The derived-number recompute caught a third error in three runs: a claim that the paper's claimed scales sit "one to four orders of magnitude" beyond its throughput, where the same 800 ms figure gives 0.85 days for a conference-scale job and 9 days for a million references, under one order.

## The pruning survey (2026-09-23)

Eight read-only agents, one per file, each reading writing-for-agents in full and working its file sentence by sentence against five named tests: duplication, no-op, relevance, cache, sediment. Every proposal carried the exact text, its replacement, and the concrete failure that would follow if the cut were wrong. The agents were given no eval history, so they arrived as fresh eyes; adjudication stayed with the main context, which knows which lines the runs proved load-bearing.

They proposed 64 cuts, about 14% of the tree. Eight were applied, all in SKILL.md, and all of them scar tissue rather than content: a stage 1 sentence that forbade what stage 4 permits, two tables of contents for briefs the agent must open anyway, a second sharper copy of the de-duplication rule, an inline venue list that had drifted from the section it points at, a re-listing of the appendix contents the outline already specifies, the same Novelty question asked twice, and a leftover clause from removing the word ceiling.

**Why the other 56 were declined, and what it says about the lever.** The agents wrote honest risk statements, and most of those statements argue against their own proposals: "loses its not-stated entry", "draws no sampling point", "a fabricated citation survives to delivery". The duplication test assumes one reader moving through one document. The five reference files are branch-loaded in different subsets, so a paper with an experiment and no participants loads one and not another; an item appearing in two of them is redundant only for a run that loads both, and cutting it breaks every run that loads one. For a file whose whole job is to prompt a check the judge would otherwise skip, removing a prompt removes the check. Two proposals were blocked by the drift test rather than by judgement, which is the mechanism working as intended, and two high-confidence proposals targeted lines the author had restored by hand in earlier passes.

The honest reading is that the tree is tight where tightness matters and that this lens misfires on branch-loaded reference material. A later pass wanting to shrink the references should measure which items a real run actually consults, not which items appear twice.

## Micro-testing the search directive (2026-09-23)

The Context section carried four canned query templates: "[paper topic] state of the art [current year]", "[key method name] comparison benchmark", "[authors] previous work [topic]", "[specific technique] limitations criticism". The question was whether a more general directive should replace them. Because this is behaviour-shaping wording, the standard prescribes a micro-test against a no-guidance control rather than an argument, and none of these strings had ever fired: every earlier run had web access switched off in its brief for comparability, which was the author's choice and not a capability limit.

Four variants, two reps each, all eight running their searches for real against the test paper: no guidance at all, the four canned strings, a slot-bound directive composing queries in the field's own vocabulary, and a fully open "search for whatever the slots need".

**The templates did not constrain.** Reps given the four strings ran 21 to 22 searches; reps given no templates or a general directive ran 19, 23, 24 and 29. Search count is if anything higher without them, so the specificity bought no demand. Unanswered slots came back at three to five across every variant, so the templates bought no coverage either.

**Every rep reported the same transfer failure, unprompted.** Asked whether their own queries would survive on a qualitative interview study in medical sociology and on a historical archival paper, all eight said the author-identity query transfers and the rest breaks: an arXiv identifier, "state of the art", and "comparison benchmark" are computer-science idioms in a skill that ships qualitative-methods and participants files.

**The best findings came from queries no template suggested.** Across reps: a GESIS benchmark paper that names the tool under review and reports it flagging 34 to 36 valid references as problematic; the paper's motivating statistic chased back from the news article it cites to the primary scan behind it; a confirmed wrong year on a cited reference inside a paper about citation accuracy; an uncited citation-verification framework released two months earlier; and a reference cited twice for a claim about pricing that the cited study never makes. Several reps said outright that their highest-yield moves were not templates at all, and that the queries which broke on transfer were the ones that produced their best findings.

So the four strings are gone. In their place the slots themselves carry the demand, since even the least-guided reps ran nineteen or more searches driven by the slots, and two moves that paid off in every rep are named because neither is obvious: follow the paper's load-bearing external claim back to its primary source rather than the account it cites, and resolve one cited reference against a citation index to check the metadata the paper states for it.

## The partition, re-evaluated (2026-09-23)

## Leading words (2026-09-23)

Three hunts over the same measured tree — spelled-out triads, fuzzy gates that could become observable states, and sentences gesturing at an unnamed idea — then a judge applying five tests in order: is the word pretrained, does it repeat three times or more, does it beat the default, does it lose precision against an enumeration a failed run put there, and does it fight an anchor the tree already has.

The measurement that grounded it: cross-file repetition of four words or more was almost entirely the three briefs' boilerplate, and the existing anchors were thin — location 29, point 24, slot 11, verdict 7, bar 5, derived 5, probe 4, tighten 4, walk 3, fresh 2, screen 1. Several were single uses, and a word used once is a word, not an anchor.

**Two adopted.** *Admissible* names what may stand as evidence for a point, a rule the tree had been spelling out at two sites in different words; the enumeration now lives once, in the judge brief, and stage 4 screens on one predicate. The author had already reached for the word unprompted in this very record while the skill never used it. *Recall*, already the tree's word for a statement resting on what the model knows rather than on the paper, is now offered to the judge as a label beside "derived" rather than being inferred at assembly — the same three-party protocol that caught six wrong numbers in run C.

**Seven rejected, each on a named test.** *Quarantine* and *web-gated* died on beating the default, the first because the no-skill baseline already quarantined recall-based points unprompted. *Leaf* died on repetition: each brief is a standalone context, so it would appear once per reader, and it would have traded a clause added after a documented runaway fan-out for a tree metaphor handed to an agent with no tree in front of it. *Anchor*, which was my own candidate going in, lost a head-to-head with *admissible* on collision: "unanchored" bleeds onto the Location field, which stage 5 enforces separately. *Contract* competed with *brief*, and *referee* was a pruning proposal in a leading-word costume.

**Three findings the judge rated above any word, all applied.** Stage 6's dispatch and the long-paper fan-out row carried no closed-context rule where stage 3 does, so a verifier could have been handed the reasoning behind the report it was checking. The three delegation blocks stated one meaning three ways, with the verifier's variant differing for no reason. And the four point kinds were told to the judge but never recorded on the point: run D appended a kind marker to 47 points voluntarily while runs A and C appended none, and that spread across near-identical text is the signature of a missing field. Kind is now the fifth field, which also makes the non-substitution rule enforceable at stages 4 and 5 for the first time.

Also found while applying: the admissibility rule had been appended to the end of the worked example's last bullet in an earlier pass, so it read as part of the example rather than as a rule governing every point.

The falsifiers are one run each. *Admissible* did not bind if stage 4's inadmissibility count stays at one per run; it bound and misfired if the count jumps toward twenty-five, which would mean the token swallowed the ride-alongside exception. *Recall* did not bind if the archived stage 3 return carries no labels while the did-not-check section still acquires recall statements during assembly.

## Run E: the first end-to-end run with web access (2026-09-23)

Same paper as runs A, C and D, at HEAD, exercising everything since the comparison pass: six stages with assembly named, the two-table router, the merged quantitative file, the judge brief holding the bar and the nine dimensions, the verifier's Location convention, and the day's three new mechanisms.
