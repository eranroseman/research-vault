# Triage labels

Five labels, and their meaning in this repository's issue tracker:

| Label             | Meaning                                            |
| ----------------- | -------------------------------------------------- |
| `needs-triage`    | The maintainer has not evaluated this issue yet    |
| `needs-info`      | Waiting on the reporter for more information       |
| `ready-for-agent` | Fully specified; an agent can take it unattended   |
| `ready-for-human` | Needs a person: a decision, an account, a click    |
| `wontfix`         | Will not be actioned; the closing comment says why |

When a skill names a triage role ("the AFK-ready label"), use the label above that carries that meaning.
